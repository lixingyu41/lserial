# LSerial FNOS Docker Package

This package wraps the existing Flutter Web build of LSerial as a fnOS Docker
application source bundle.

It serves static files only. Serial and BLE access still happen in the user's
browser through Web Serial and Web Bluetooth.

## Important limitation

Web Serial and Web Bluetooth require a secure browser context. If fnOS opens
the app through plain HTTP, Chrome may disable these capabilities even though
the page itself loads normally.

## Architecture-specific output

The packager does not emit `platform=all` in `manifest`, because the fnOS
Manifest documentation still marks that value as "coming soon". By default it
generates one source bundle per supported architecture:

- `LSerial-FNOS-Docker-<version>-x86.zip`
- `LSerial-FNOS-Docker-<version>-arm.zip`

Import the zip that matches your fnOS device CPU architecture, then run
`fnpack build` on fnOS.

## Files generated by the packager

- `manifest`
- `app/docker/docker-compose.yaml`
- `app/docker/site/*`
- `app/docker/nginx/default.conf`
- `app/ui/config`
- `config/privilege`
- `config/resource`
- `cmd/main`
- `ICON.PNG`
- `ICON_256.PNG`

## Rebuild locally

```powershell
flutter build web --release
pwsh ./scripts/build_fnos_package.ps1
```

The generated zips are written to `dist/fnos/`.

If this zip is generated on Windows and then unpacked on fnOS, make sure the
script is executable before running `fnpack build`:

```bash
chmod +x cmd/main
```
